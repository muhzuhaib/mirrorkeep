Mirrorkeep

Mirrors a folder to a USB drive, a second disk or a NAS on Windows, showing every copy, update and delete before it happens, and keeping every replaced or deleted file in a dated safety folder you can restore from.

Questions

What does the free edition do?

The whole sync tool. Any number of folder pairs and network destinations (a mapped drive or a UNC path). Schedules that ask Windows to wake the PC where the hardware allows and otherwise catch up at the next start. The retention you choose, 10 safety folders per pair by default and never fewer than 3. A preview before any manual run that lists every copy, replacement and removal in the destination, and a run history that records every scheduled run. Dated safety folders that keep every file a run replaces or removes, with restore from inside the app. And the empty-source guard that refuses to empty a destination when the source looks empty. There is no account, no telemetry, no file count or size limit, no expiry and no countdown.

Where do replaced and deleted files go?

Into a dated safety folder inside the destination, in a folder named .mirrorkeep. A run never deletes a file outright: what it replaces or removes is moved there. The restore screen lists the safety folders for each pair and puts any file back with one click. The mirror ignores the .mirrorkeep folder itself, so the safety copies never show up as changes on a later run. The only deletion is the retention you choose: after a good run the oldest safety folders beyond your limit are retired, and the preview names the one that will go.

What happens after I restore a file?

It goes back into the destination. If the source still does not have it, the next run will move it into the safety folder again, and the restore screen says so rather than leaving it as a surprise.

What is the empty-source guard?

A refusal you want. If the source looks empty or unreadable, a run would empty a good destination, so Mirrorkeep stops and says why instead of doing it. A destination that is not there when a run starts, the wrong drive or a USB stick left in the drawer, ends as "destination not present" and touches nothing. A file that is in use is listed as not copied, the run carries on, and it ends as finished with skipped files, never as a good copy. After every run the app also checks that each file it moved into the safety folder is really there.

What does Pro add?

Scope, never permission. Named backup drives that Mirrorkeep recognises when you plug them in, with the date of the last good copy and a warning when a drive is overdue. Scheduled verification of the copies, with repair. A timeline that shows a pair as it was at any earlier run, with restore drills that prove your files come back. And a space forecast with consented pruning, plus a one-page health report per pair. It runs the same engine, writes the same safety folders and changes nothing about how the free edition behaves.

What does Pro cost, and how do I cancel?

The Microsoft Store sells Pro two ways with the same scope: one payment of 9.99 US dollars, yours for good on your Microsoft account, or 0.99 US dollars a month as a subscription. The monthly plan is managed by the Microsoft Store, under Subscriptions in the Store app. Cancelling stops the renewal, the free edition keeps working exactly as before, and your pairs, run logs and every safety folder are unaffected.

What is the tray helper?

Named backup drives are recognised by a small helper that Windows starts when you sign in. It exits at once unless Pro is on, and it can be turned off in Windows Settings under Apps, Startup. It collects nothing and sends nothing.

Which destinations can I mirror to?

Any folder Windows can see: a USB drive, a second disk, another folder on the same PC, or a mapped drive or a UNC path on your LAN, all in the free edition. There are no cloud providers, no accounts and no sync service.

Is it one way or two way?

One way, source to destination, by design. It is not a merge: deleting a file in the source is meant to remove it from the destination, and the safety folder is the way back. That is what makes the destination a faithful mirror of the source.

Why was a file I just changed not copied?

Timestamps are compared with a two second tolerance, so cheap USB drives formatted FAT or exFAT do not re-copy everything on every run. A file changed within two seconds of its copy can therefore wait until its next change to be picked up.

Does it need an internet connection?

No. Mirroring runs entirely on your computer. The only network paths the app can touch are destinations you explicitly choose that are on your LAN. Licence checks and purchases are handled entirely by the Microsoft Store, and there is no telemetry, no analytics and no account.

Which Windows versions does it run on?

Windows 10 version 2004 or newer, 64 bit, including Windows 11.

What does it cost?

Mirrorkeep is free on the Microsoft Store, and the free edition is a complete product. Optional Pro adds named backup drives, scheduled verification with repair, a restore timeline with drills, and a space forecast with a health report, for one payment of 9.99 US dollars or 0.99 US dollars a month. Everything the free edition does keeps working whether or not Pro is bought.
