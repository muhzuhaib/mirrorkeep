Mirrorkeep

Mirrors a folder to a USB drive, a second disk or a NAS on Windows, showing every copy, update and delete before it happens, and keeping every replaced or deleted file in a dated safety folder you can restore from.

Questions

What does the free edition do?

The whole sync tool. One folder pair, previewed before every run so every copy, replacement and removal in the destination is listed before anything happens. A dated safety folder that keeps every file a run replaces or deletes, with restore from inside the app. The wipe guard that refuses to empty a destination when the source looks empty. And the last three safety folders are kept per pair. There is no account, no telemetry, no file count or size limit, no expiry and no countdown.

Where do replaced and deleted files go?

Into a dated safety folder inside the destination, in a folder named .mirrorkeep. Nothing a run replaces or removes is deleted for good. The restore screen lists the safety folders for each pair and puts any file back with one click. The mirror ignores the .mirrorkeep folder itself, so the safety copies never show up as changes on a later run.

What happens after I restore a file?

It goes back into the destination. If the source still does not have it, the next run will move it into the safety folder again, and the restore screen says so rather than leaving it as a surprise.

What is the wipe guard?

A refusal you want. If the source looks empty or unreadable, a run would empty a good destination, so Mirrorkeep stops and says why instead of doing it. The same plain sentence rule covers everything else: a pulled USB drive, a locked file or a missing folder stops the run and says what happened. After every run the app also checks that each file it moved into the safety folder is really there.

What does Pro add?

Scope, never permission. Unlimited folder pairs instead of one. Schedules that wake the PC to run a pair and catch up a run that was missed while the PC was off. Retention you choose, keeping every dated safety folder per pair instead of the last three, with restore from any of them. And network destinations: a mapped drive or a UNC path on your LAN. It runs the same engine, writes the same safety folders and changes nothing about how the free edition behaves.

How do I cancel or manage a Pro subscription?

Subscriptions are managed by the Microsoft Store, under Subscriptions in the Store app. Cancelling stops the renewal, the free edition keeps working exactly as before, and your pairs, run logs and every safety folder are unaffected.

Which destinations can I mirror to?

Any folder Windows can see: a USB drive, a second disk, another folder on the same PC, or with Pro a mapped drive or a UNC path on your LAN. There are no cloud providers, no accounts and no sync service.

Is it one way or two way?

One way, source to destination, by design. It is not a merge: deleting a file in the source is meant to remove it from the destination, and the safety folder is the way back. That is what makes the destination a faithful mirror of the source.

Why was a file I just changed not copied?

Timestamps are compared with a two second tolerance, so cheap USB drives formatted FAT or exFAT do not re-copy everything on every run. A file changed within two seconds of its copy can therefore wait until its next change to be picked up.

Does it need an internet connection?

No. Mirroring runs entirely on your computer. The only network paths the app can touch are destinations you explicitly choose that are on your LAN, and only Pro accepts those. Licence checks and purchases are handled entirely by the Microsoft Store, and there is no telemetry, no analytics and no account.

Which Windows versions does it run on?

Windows 10 version 2004 or newer, 64 bit, including Windows 11.

What does it cost?

Mirrorkeep is free on the Microsoft Store, and the free edition is a complete product. Its optional Pro subscription, 2.99 US dollars per month, adds unlimited folder pairs, schedules that wake the PC and catch up a missed run, retention you choose, and network destinations. Everything the free edition does keeps working whether or not Pro is bought.
